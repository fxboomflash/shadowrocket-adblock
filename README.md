# Shadowrocket 广告拦截模块

完整合集的固定导入 URL：

```text
https://raw.githubusercontent.com/fxboomflash/shadowrocket-adblock/main/shadowrocket-adblock.srmodule
```

## 使用

1. 在 Shadowrocket 打开「配置 → 模块 → ＋」，粘贴上面的 URL，下载并启用「广告拦截融合版 · GitHub 固定链接版」。
2. 关闭旧广告合集，保留原来的订阅、节点和主配置；首页「全局路由」使用「配置」。
3. 继续使用你自己已安装并完全信任的 HTTPS 解密证书。断开后重新连接 Shadowrocket，彻底退出目标 App 后再打开。

只导入这一个模块。它会自行下载本仓库的 10 份脚本和 2 份规则表。GitHub 访问情况取决于所在网络；链接下载失败时可先使用已有代理连接。

以后沿用同一 URL，在模块页面更新模块后重新连接。仓库不会向手机推送更新，也不提供后台维护或定时更新承诺。出现误拦时可以暂时关闭模块，原节点订阅仍由主配置管理。

## 本次发布

2026-10-21 将 2026-10-18 的完整模块迁移到 GitHub。除模块名称、说明和资源下载地址外，生效配置、脚本及规则表内容保持一致。这次发布本身没有新增广告拦截规则。

覆盖已有 App 开屏、部分广告弹层与网页广告服务器，包括闲鱼、淘宝、京东、B站、酷狗、航旅纵横、去哪儿、菜鸟、贴吧等既有处理。288,862 个列名域名和 277 条关键词是规则规模，不是广告数量，也不表示所有域名当前都在投放广告。

对可识别的网络广告接口进行拒绝或本地响应处理；未知接口、不能解密的请求、App 已缓存的素材，以及与正文同接口的网页广告，可能仍然显示。不能保证所有应用、所有网页无广告。该版本未在真实 iPhone 上验证。

此仓库不包含代理节点、订阅链接、账号配置、证书私钥或托管管理回执。模块包含公共广告规则及其运行脚本；下载资源会向 GitHub 发出正常的下载请求。

资源名包含内容哈希，便于核对和回滚。第三方规则及改编脚本保留原来源和相应许可，见 [SOURCES.md](SOURCES.md)、[licenses/](licenses/) 与文件中的注释。本仓库没有用单一许可覆盖所有第三方内容。

```sh
python3 tools/verify.py
```

可选：联网核对固定导入地址及 12 份依赖是否已公开可下载：

```sh
python3 tools/verify.py --online
```

校验会检查文件哈希、资源引用、配置结构和发布文件中的节点/证书字段；不能代替真实手机上的广告及正常业务测试。基线的本地检查结果见 [verification/baseline-validation.json](verification/baseline-validation.json)。
